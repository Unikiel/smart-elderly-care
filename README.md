# Care surveys

Surveys for elders, families, and staff. English only. Answers are stored in `data/store.json`. No database is required.

## Local preview

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

| Path | What it is |
|---|---|
| `/` | Home |
| `/s/ai-demo` | AI elderly care survey |
| `/s/meal-demo` | Meal follow-up |
| `/login` | Staff |

Demo account: `admin` / `changeit`
